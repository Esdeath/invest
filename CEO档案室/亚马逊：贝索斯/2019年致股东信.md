# 2019年致股东信：



致我们的股东：



从新冠疫情危机中我们学到的一件事，是亚马逊对客户变得多么重要。我们希望您知道我们对这一责任非常认真，也为我们的团队正在为帮助客户度过这段困难时期所做的工作感到自豪。



亚马逊员工昼夜不停地工作，努力将必要物资直接送达有需要人们的家门口。我们看到对基本生活用品的需求持续高涨。但与可预测的假日购物高峰不同，这次激增几乎没有预兆，给我们的供应链和配送网络带来了巨大挑战。我们迅速优先保障了家庭常用必需品、医疗用品和其他关键商品的备货和配送。



我们的全食超市（Whole Foods Market）门店保持营业，为顾客提供新鲜食品和其他生活必需品。我们采取了多项措施来帮助最容易受到病毒影响的人群，例如为老年人群体预留了每天在全食门店购物的第一个小时。同时，我们暂时关闭了Amazon Books、Amazon 4-star和Amazon Pop Up等非生活必需品门店，并为这些门店的员工提供了重新分配到亚马逊其他业务部门的机会。



最关键的是，在提供这些基本服务的同时，我们也始终把全球各地员工和承包商的安全放在首位。我们对他们的英勇付出深感感激，并致力于保障他们的健康与福祉。在与医学专家和卫生机构密切协作下，我们已经对运营网络和全食超市门店实施了超过150项重大流程变更，以帮助团队保持健康，并每日进行现场措施的审查。我们分发了口罩，实施了体温检测制度，定期对门把手、楼梯扶手、储物柜、电梯按钮、触摸屏等进行消毒，消毒湿巾和洗手液也成为我们网络中的标准配备。



我们还推行了广泛的社交距离措施，以进一步保护员工安全。我们取消了班次间的站立会议，将信息传递从公告板转为电子方式，错开了休息时间，并增加了休息区座位间的间隔。虽然在新规下对新员工的培训变得更具挑战，但我们仍确保每位新员工都能完成六小时的安全培训。我们调整了培训流程，避免员工聚集，并在招聘流程中也引入了社交距离的要求。



为进一步保护员工，我们正在考虑对所有亚马逊员工进行定期病毒检测，包括没有症状的员工。在全球范围、跨行业大规模地开展检测，将有助于确保人们的安全并推动经济恢复。但要做到这一点，我们作为一个社会，需要比现有水平高得多的检测能力。如果每个人都能定期检测，就能极大地改善我们控制疫情的方式。检测结果呈阳性的人可以被隔离和治疗，而结果为阴性的人可以有信心地重新进入工作岗位。



我们已经开始着手建设内部检测能力。由亚马逊多个部门——从科研人员和项目经理到采购专家和软件工程师——组成的团队，已经暂时离开原本的工作岗位，专门组建了一个团队来推进这一项目。我们已经开始采购所需设备，着手建设第一个实验室，并准备先在一线员工中进行小规模测试。我们还不知道能走多远、进展多快，但我们相信值得一试，也已经准备好迎接任何挑战。



在我们探索长期解决方案的同时，我们也致力于立即支持员工。我们在美国将最低时薪提高了2美元，在加拿大也提高了2美元，在英国提高了2英镑，在其他欧洲国家提高了2欧元，该调整将持续至4月底。同时，我们还按照加班标准支付给员工至少每小时34美元的工资——这是原工资的一倍半。这些加薪措施仅在4月底前就将带来超过5亿美元的成本，未来还可能更多。虽然我们知道这笔支出巨大，但我们认为在当前情况下，这么做是正确的事情。



我们还设立了“亚马逊救助基金”，初期拨款2500万美元，用于帮助我们的独立配送服务合作伙伴及其司机、Amazon Flex灵活用工人员以及在财务困难中的临时员工。



在三月份，我们在配送和履约网络中新增了10万个岗位。就在本周，在这些岗位成功填补之后，我们又宣布将新增7.5万个工作岗位，以应对持续增长的客户需求。这些新员工正在为依赖我们完成关键需求的顾客服务。我们知道，全球许多人因疫情失业或被迫停职而遭受经济困境。我们很高兴能在这个时期接纳他们加入我们的团队，直到情况恢复正常，或者他们原本的雇主能将他们召回，或者他们能找到新工作为止。



我们欢迎了例如 Joe Duffy 这样的员工，他在新泽西纽瓦克机场失去了安检员的工作，并从亚马逊一位员工朋友那得知我们在招聘。我们还欢迎了德克萨斯州达拉斯的一位幼儿园教师 Darby Griffin，她在3月9日学校关闭后加入了我们，协助处理新的库存需求。我们很高兴 Darby 能与我们共事，直到她能回到教室工作。



亚马逊正采取强有力的措施，保护顾客不受不法分子欺诈。我们已经下架了超过50万个因哄抬疫情相关商品价格而违规的商品，并暂停了全球6000多个销售账号，这些账号违反了我们的公平定价政策。亚马逊还将涉及疫情期间哄抬物价的卖家信息报告给了42个州的总检察长。为更高效地应对哄抬物价问题，我们还创建了专门的沟通渠道，以便州检察官快速、安全地向我们反馈消费者投诉，并迅速采取行动。



亚马逊云服务（AWS）在这场危机中也发挥着重要作用。无论是用于远程医疗服务、帮助学生继续学习、支持前所未有数量的远程办公员工，还是为疫情中的应急响应提供支持，AWS所提供的可扩展、可靠和高度安全的计算能力都至关重要。医院网络、制药公司和研究机构都在使用AWS来服务患者、优化治疗方案，并缓解疫情带来的影响。世界各地的学术机构也正在从面对面教学转向虚拟课堂，并依靠AWS来保证教育的连续性。政府也在使用AWS作为可信的平台，快速构建和部署新能力，以应对这场全球大流行。



我们也在与世界卫生组织（WHO）密切合作，利用先进的云技术和技术专长来追踪病毒、理解疫情发展并更好地遏制其传播。世卫组织正在使用我们的云服务构建大型数据湖，聚合全球疫情数据，建立流行病学模型，快速翻译医学培训视频并将其推广到不同语言地区，同时帮助全球公共卫生工作者更好地治疗患者。我们还为公共机构提供免费的COVID-19数据湖，使研究人员能够获取最新的数据，以便专家分析病毒传播路径和特征，并做出快速科学的响应。



我们还启动了“AWS 诊断开发计划”，该项目旨在支持客户开发更精确的 COVID-19 诊断解决方案。更好的诊断手段有助于加快治疗进程并遏制疫情蔓延。我们承诺投入2000万美元来加速这项工作，帮助客户利用云技术应对这一挑战。虽然该项目最初是为应对 COVID-19 而设立的，但我们也着眼于未来，计划资助那些有潜力减缓未来传染病暴发的诊断研究项目。



全球的客户都在利用云技术扩展服务并开展 COVID-19 应对工作。我们加入了纽约市 COVID-19 快速响应联盟，开发对话式代理，帮助高风险人群和老年人获取及时的医学信息和其他重要资源。应洛杉矶联合学区的请求，AWS 协助学校将7万名学生转为远程学习，建立呼叫中心以回答IT相关问题、提供远程支持并安排人员接听电话。我们还向美国疾控中心（CDC）提供云服务，帮助数千名公共卫生专业人士和临床医生收集 COVID-19 相关数据，为疫情响应提供信息参考。



在英国，AWS 为国家医疗服务系统（NHS）提供云计算基础设施，用于分析医院床位使用率、急诊容量以及病人等待时间，帮助该国合理分配资源。在加拿大，全球最大虚拟医疗网络之一 OTN 使用 AWS 云服务以应对4000%的流量激增，支持疫情期间民众的远程医疗需求。在巴西，AWS 正与圣保罗州政府合作，提供云计算基础设施以保障该州100万名中小学学生能够远程上课。



根据 CDC 指南，我们的 Alexa 医疗团队开发了一项功能，允许美国用户在家中评估自己感染 COVID-19 的风险。用户可以询问 Alexa：“我觉得我感染了 COVID-19，该怎么办？”或“如果我觉得自己可能感染了新冠病毒，该怎么办？”Alexa 将引导用户回答一系列问题，评估症状和可能的接触史，然后根据 CDC 的数据提供建议。我们还在日本上线了类似的服务，依据的是日本厚生劳动省的指南。



我们还为用户提供便利的方式，通过 Amazon.com 或 Alexa 向处于疫情一线的慈善机构捐款，包括 Feeding America、美国红十字会和 Save the Children 等。用户只需说：“Alexa，向 Feeding America COVID-19 响应基金捐款。”在西雅图，我们与餐饮公司合作，为2700名老年人和免疫力低下人群配送了7.3万份餐食，还向当地公立学校捐赠了8200台笔记本电脑，以帮助学生在家中完成远程学习。



尽管现在是极其艰难的时刻，但这也提醒我们，作为一家企业，我们所做的事情仍可以对人们的生活产生巨大影响。客户依赖我们，相信我们；我们很幸运能成为他们的依靠。凭借我们的规模和快速创新能力，亚马逊可以成为推动进步的积极力量。



去年，我们与联合国前气候变化事务高级代表 Christiana Figueres 及其创办的 Global Optimism 联合发起了“气候承诺”（The Climate Pledge），并成为首个签署方。该承诺要求亚马逊比《巴黎协定》提前十年实现其目标——在2040年实现碳中和。实现这一目标面临巨大挑战，因为亚马逊不仅仅是信息流通公司，我们拥有庞大的实体基础设施，每年交付超过100亿件商品。但我们相信，如果亚马逊能够提前十年实现碳中和，那任何公司都能做到——我们也希望与所有公司共同努力，将这一愿景变为现实。



为此，我们正在招募更多公司加入“气候承诺”。签署方需定期报告温室气体排放量，并依照《巴黎协定》制定并执行脱碳战略，以确保在2040年前实现净零碳排放。（我们很快将公布新的签约方。）



为了实现这一承诺，我们计划采购10万辆来自Rivian的电动送货车。Rivian是一家总部位于密歇根州的电动车制造商。亚马逊计划于2022年前上线1万辆Rivian新款电动送货车，并在2030年前实现10万辆车辆全部上路。这不仅有益于环境，更重要的是，它向市场发出了一个强烈信号——大型全球企业必须转向低碳经济。



我们还承诺，到2024年实现80%的可再生能源使用率，并在2030年前实现100%。（事实上，我们的团队正努力在2025年前就达到100%，尽管这目标艰巨，但具备可实现性。）目前，亚马逊在全球已建设了86个太阳能和风能项目，总发电能力达2300兆瓦，每年可生产超过630万兆瓦时的清洁能源，足以供电超过58万个美国家庭。



我们在减少包装浪费方面也取得了巨大进展。十多年前，我们启动了“无烦恼包装”计划，鼓励制造商将产品包装为易开启、可100%回收、无需额外运输包装的形式直接发货给客户。自2008年启动以来，该计划已经减少了超过81万吨包装材料的使用，相当于节省了14亿个纸箱。



我们之所以做出这些重大投资，是为了将碳足迹降为零，尽管事实上，线上购物本身就比传统到店购物更具碳效率。亚马逊的可持续发展科学家花费三年时间开发了模型、工具与衡量标准，用以计算我们的碳足迹。他们的详细分析发现，线上购物在大多数情况下比驾车去商店的碳排放更低。例如，单次送货车行程相当于减少了100次家庭往返商店的行程。我们的科学家还开发了模型，比较线上订购 Whole Foods 食品与前往实体店购物的碳强度。研究结果显示，平均而言，线上 Whole Foods 食品配送的碳排放比到店购物低43%；而购物篮越小，节省的碳排放就越大。



AWS 也比传统的数据中心更高效。这主要归功于两个因素：更高的利用率，以及我们的服务器和设施比大多数公司自建的数据中心更节能。一项由 451 Research 发布的研究发现，亚马逊云计算基础设施的能效是美国中位企业自建数据中心的3.6倍。结合我们对可再生能源的大量使用，这些因素共同促使 AWS 能以88%更低的碳足迹完成与传统数据中心相同的计算任务。我们认为实现最后这12%的减排并非不可能——我们将继续推进 AWS 100%使用可再生能源的目标。



**善用规模造福社会**



在过去十年中，没有哪家公司像亚马逊一样创造了如此多的就业机会。亚马逊目前在全球直接雇佣了84万人，其中包括美国的59万人、欧洲的11.5万人以及亚洲的9.5万人。总体而言，亚马逊在美国直接和间接支持了200万个就业岗位，其中包括亚马逊在建筑、物流和专业服务等领域的投资所创造的超过68万个岗位，另有83万个岗位是由在亚马逊平台上销售商品的中小型企业创造的。放眼全球，我们支持着近400万个就业岗位。我们尤其自豪的是，许多这些工作属于入门级，为人们提供了第一次进入职场的机会。



亚马逊的这些工作岗位还提供了业内领先的15美元最低时薪以及全面的福利待遇。超过4000万美国人——其中许多人仍以联邦标准的7.25美元/小时作为工资——其收入还不及亚马逊最低薪资员工的水平。当我们在2018年将最低起薪提高到15美元/小时时，这一举措立即对我们履约中心的数十万员工产生了重要且积极的影响。我们希望其他大型雇主能效仿我们的做法，提高他们自己的最低工资标准，并且我们也在持续推动联邦层面实施15美元最低工资。



**改善员工生活，投资未来**



我们致力于改善员工的整体生活，而不仅仅是工资。亚马逊为每位全职员工提供健康保险、401(k)退休储蓄计划、20周带薪产假以及其他福利待遇。这些福利待遇与我们高管层享有的相同。在当前迅速变化的经济环境中，我们比以往任何时候都更清楚地看到，员工需要不断提升自身技能以跟上技术发展步伐。因此，我们投入7亿美元，为超过10万名亚马逊员工提供培训课程，覆盖医疗保健、云计算和机器学习等高需求领域。自2012年以来，我们推出了“职业选择”项目，该项目为希望进入更高技术含量岗位的履约中心员工预付最多95%的学费和杂费，帮助他们获得证书或副学位。截至目前，已有超过2.5万名亚马逊员工完成了该项目提供的相关职业培训。



为了确保下一代在技术驱动的经济中具备成功所需的技能，我们去年启动了“亚马逊未来工程师”项目（Amazon Future Engineer），旨在帮助低收入和弱势群体青少年获得计算机科学方面的教育和培训。我们的目标是每年帮助数十万学生学习计算机科学和编程课程。目前，该项目在全美2000多所服务欠缺社区学校中开设计算机入门课程和AP计算机课程。每年，该项目还为来自低收入家庭的学生提供100个为期四年的大学奖学金（每份4万美元），并在他们大学第一年后安排带薪实习。我们的英国项目还为120名学生提供工程学徒机会，帮助他们追求科技职业。
