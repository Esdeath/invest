# 2014年致股东信：



致我们的股东：



一个梦想中的商业产品至少具备四个特征：顾客喜欢它，它具有可扩展性，可以成长为非常大的规模，它对资本回报率高，并且具有时间的耐久性——有可能持续数十年。当你找到这样一个机会时，不要只是轻轻划过，就应该“结婚”。



很高兴地告诉大家，亚马逊在这方面并不专一。在过去二十年的冒险与合作中，伴随着不断的好运气，我们现在已经幸福地“嫁给”了我认为的三个如此优质的“人生伴侣”：Marketplace（市场）、Prime（会员服务）和 AWS（云服务）。每一个最初都是一个大胆的赌注，刚开始时人们（经常）担心它们可能无法运作。但如今，很显然我们很特别，也很幸运拥有它们。同时也很清楚，在商业中没有“铁饭碗”。我们知道，滋养和强化这些业务，是我们责无旁贷的使命。



我们会用一贯的方式来执行任务：以客户为中心，而不是以竞争对手为导向；对发明抱有由衷的热情；致力于卓越运营；并愿意以长期思维去行事。只要执行得当，再加上一点持续的好运气，Marketplace、Prime 和 AWS 就能在未来多年持续为客户服务，并带来可观的财务回报。



**Marketplace（市场）**



Marketplace 最初并不顺利。我们最初推出的是 Amazon Auctions。我记得来了七个人，如果你把我的父母兄弟姐妹都算上。拍卖后来变成了 zShops，本质上是个定价版本的拍卖平台。还是没有客户。但后来我们把 zShops 转变为现在的 Marketplace。在内部，Marketplace 被称为 SDP，即“单一详情页”（Single Detail Page）。我们的想法是将我们最有价值的零售房地产——产品详情页——用于第三方卖家，让他们与我们的零售品类经理直接竞争。这对于顾客来说更方便，在推出一年内就占据了 5% 的销售量。如今，我们超过 40% 的订单来自全球两百多万名第三方卖家。2014年，顾客从这些卖家那里下单超过二十亿件商品。



这种混合模式的成功推动了亚马逊飞轮的加速运转。最初吸引顾客的是我们不断增长的精选商品和极具性价比的购物体验。随着我们允许第三方卖家在同一页面上直接销售商品，我们的吸引力增加了，更多卖家加入，也加强了我们的规模经济。通过为符合条件的订单免运费，我们进一步降低了价格。这些举措最初在美国推出后，我们也将它们扩展到了其他地区。最终的结果是，Marketplace 成为了一个无缝集成的全球平台。



我们还致力于减轻卖家的工作负担并提升他们的业务成功率。通过我们的 Selling Coach 计划，我们每周都会自动生成超过 7000 万条由机器学习算法提供的“提示”，提醒卖家避免断货、补充热门商品、并优化价格以增强竞争力。这些提示最终为卖家带来了数十亿美元的销售增长。



为了进一步推动 Marketplace 的全球化，我们正在为各地区的卖家提供支持，甚至在我们尚未进入的国家中，也帮助他们接触到本地以外的客户。去年，我们为来自 100 多个国家的商家提供平台，帮助他们与分布在 185 个国家的客户建立联系。



我们目前几乎五分之一的整体第三方销售发生在卖家所在国家以外的地区，而我们商家的跨境销售额在去年几乎翻了一番。在欧盟，卖家可以开设一个统一账户，用多种语言管理业务，并在我们五个欧洲网站上提供产品。最近，我们还开始整合卖家的跨境运输，帮助他们以优惠的批量价格将海运货物从亚洲运送到欧洲和北美。



Marketplace 是我们在印度快速增长业务的核心，因为我们在印度的所有商品都由第三方卖家提供。Amazon.in 现在的商品种类比印度任何其他电商网站都要多——有超过 2100 万种商品，由超过 21,000 个卖家提供。通过我们的 Easy Ship 服务，我们从卖家手中提取商品，并将其配送至最终顾客手中。在 Easy Ship 基础上，印度团队最近还试点推出了 Kirana Now 服务，这是一项从当地杂货店（夫妻店）配送日常必需品的服务，配送时间在 2 至 4 小时之间，为顾客提供了便利，同时也提高了参与商家的销售额。



也许对卖家来说最重要的是，我们创建了亚马逊配送服务 Fulfillment by Amazon。但这部分内容我们会在介绍 Prime 后再展开。



**Amazon Prime**



十年前，我们推出了 Amazon Prime，最初设想为一个包年不限量的免费快速配送项目。我们一再被告知这是一个风险巨大的举措，从某些方面来看确实如此。在第一年里，我们放弃了数百万美元的运输收入，而且没有任何简单的数学模型能说明这个决定是否值得。但我们之所以决定推进，是基于我们在推出 Free Super Saver Shipping 时看到的积极结果，以及一种直觉——即顾客会迅速意识到这是购物历史上最划算的交易之一。此外，分析也告诉我们，如果能实现规模化，我们将能大幅降低快速配送的成本。



我们自有库存的零售业务是 Prime 的基础。除了组建各品类“在线商店”的零售团队之外，我们还创建了大规模系统，以自动化管理库存补货、库存布局和产品定价。Prime 对交付日期的精准承诺要求我们以全新的方式运营配送中心，而将这一切整合在一起正是我们全球运营团队的重要成就之一。我们的配送中心网络已从 2005 年的 13 个扩展到今年的 109 个。我们目前已进入第八代配送中心设计阶段，采用专有软件管理收货、存储、拣货和发货。自 2012 年收购 Kiva 起，我们的 Amazon Robotics 部门已部署超过 15,000 台机器人，用于更高密度、更低成本地存取产品。我们的自有库存零售业务仍然是 Prime 最佳的顾客获取工具，也是构建吸引流量和第三方卖家的关键类目建设平台。



虽然快速配送仍然是 Prime 的核心优势之一，但我们正探索为 Prime 注入活力的新方式。其中两个最重要的领域是数字内容与设备。



2011 年，我们为 Prime 增加了 Prime Instant Video（即“Prime 免费视频”）的权益，允许用户在美国无限制地观看上万部电影和剧集。我们也开始将该服务拓展至英国和德国。我们正对内容进行大量投资，并密切关注其影响力。我们经常反问自己，它值得吗？它是否推动了 Prime 的发展？在评估方面，我们关注的是 Prime 免费试用的转化率、付费会员的续订率，以及通过该频道获得的产品购买行为。我们喜欢目前看到的迹象，也希望它能带来更多的成果。



虽然我们对 Prime Instant Video（PIV）的支出大多用于授权内容，但我们也开始开发原创内容。团队开局非常强劲。我们的节目《透明人生》（Transparent）成为首个凭借剧集荣获金球奖的流媒体节目，而《树屋侦探》（Tumble Leaf）也荣获安妮奖最佳学龄前动画系列。除了赢得好评外，数据也非常令人鼓舞。我们原创节目的一个优势在于首播平台是 Prime ——也就是说，它之前从未在其他地方播出。结合节目本身的高质量，这种首播地位似乎正是带来亮眼成绩的因素之一。我们也很喜欢原创节目的固定成本属性，因为我们能将这部分固定成本分摊到庞大的会员基数上。最后，我们原创内容的商业模式是独一无二的。我几乎可以肯定我们是首个能把“赢得金球奖”转化为电动工具和婴儿湿巾销量增长的公司！



亚马逊还设计并制造了 Kindle、Fire TV 和 Echo 等设备，这些设备也为 Prime 服务注入活力，例如 Prime Instant Video 和 Prime Music，进而在亚马逊生态系统的各个环节中带动更高的用户参与度。而且我们还有更多新品在路上 —— 设备团队手握强劲且令人振奋的产品路线图。



Prime 在其最初“免费且快速配送”的承诺上也从未停止创新。最近推出的 Prime Now 服务为 Prime 会员提供了数万个商品的两小时免费配送，或者支付 7.99 美元费用即可享受一小时送达。很多早期评价都是这样的：“过去六周里，我和丈夫通过 Prime Now 下单的次数已经多得数不过来了。便宜、方便、超级快。”目前该服务已在曼哈顿、布鲁克林、迈阿密、巴尔的摩、达拉斯、亚特兰大和奥斯汀上线，更多城市即将加入。



现在，我想谈谈亚马逊配送（Fulfillment by Amazon，简称 FBA）。FBA 如此重要，是因为它像胶水一样紧密地将 Marketplace 和 Prime 联系在一起。正因如此，Marketplace 和 Prime 不再是两个独立的部分。事实上，现在我甚至无法把它们分开来看。它们的经济结构和客户体验已经深度融合，密不可分。



FBA 是面向 Marketplace 卖家的服务。当卖家选择使用 FBA，他们会将库存存放在我们的配送中心。我们负责所有物流、客服和退货处理。如果一位顾客同时订购了 FBA 商品和由亚马逊自营的商品，我们可以将两者打包在同一个包裹中配送 —— 这是一项巨大的效率提升。但更重要的是，一旦卖家使用 FBA，他们的商品就可以成为 Prime 合格商品。



牢牢把握显而易见的道理，其实比你想象中要难。但这个问题值得思考。你问：“卖家真正想要的是什么？”显而易见的答案是：他们想要更多销量。那么，当卖家使用 FBA 且其商品成为 Prime 合格商品时，会发生什么？他们的销量会上升。



从 Prime 会员的角度来看，每次有新卖家加入 FBA，Prime 会员就能享受到更多 Prime 合格商品的选择，会员服务的价值随之提升。这对我们的增长飞轮来说极为关键。FBA 完成了这个闭环：Marketplace 为 Prime 注入动力，而 Prime 又反过来推动 Marketplace。



根据 2014 年美国卖家的调研，71% 的 FBA 卖家表示其在加入 FBA 后单位销售额增长超过 20%。在假日销售季中，使用 FBA 的商品出货量同比增长超过 50%，而 FBA 卖家的订单占所有第三方订单的比例超过 40%。Prime 会员在美国的增长超过 50%，在全球增长 53%。FBA 对顾客和卖家而言都是双赢之举。



**亚马逊云服务（Amazon Web Services）**



亚马逊云服务（Amazon Web Services，简称 AWS）在九年前推出时，是一个激进的构想，如今它已经规模庞大并快速成长。最早采用它的是初创企业。按需、按使用量付费的云存储和计算资源极大地提升了新业务的启动速度。Pinterest、Dropbox 和 Airbnb 等公司都使用过 AWS 服务，并且至今仍是其客户。



从那以后，大型企业也纷纷加入使用 AWS 的行列，他们选择 AWS 的原因与初创公司相同：速度和敏捷。IT 成本更低确实具有吸引力，有时还能带来可观的绝对节省，但单凭节省成本无法弥补性能或功能上的不足。企业依赖 IT —— 这是关键任务。因此，“我能为你一年节省一大笔 IT 支出，而我的服务几乎和你现有的一样好”这样的说法，很难打动客户。客户真正关心的是“更好且更快”，如果还能顺带节省成本，那自然更好。但成本节省只是甜点，不是主菜。



IT 的杠杆作用极大。你不会希望你的竞争对手的 IT 部门比你更灵活。每家公司都有很多技术项目希望尽快落地。残酷的现实是：必须优先处理的项目总是太多，许多项目最终被放弃。即便获得资源的项目，也常常延迟交付或功能不完整。如果 IT 部门能找到方法更快速地交付更多赋能业务的技术项目，他们就能为企业创造重大而真实的价值。



这也是 AWS 成长如此迅速的主要原因。IT 部门意识到，一旦采用 AWS，能完成更多工作。他们花更少时间在低附加值的活动上，例如管理数据中心、网络、操作系统补丁、容量规划、数据库扩展等等。同时，他们还获得强大 API 访问权限，这些 API 和工具极大地简化了可扩展、安全、稳定、高性能系统的构建。而这些 API 和工具都在幕后无缝持续升级，无需客户操心。



如今，AWS 拥有超过一百万家企业和组织客户，涵盖各类业务领域。2014 年第四季度，AWS 使用量同比增长约 90%。GE、美国职业棒球大联盟、塔塔汽车、澳航等公司都在 AWS 上构建新应用 —— 从众包平台、个性化健康服务，到车队管理的移动应用。其他客户如 NTT 都科摩、金融时报和美国证券交易委员会则在利用 AWS 分析并处理海量数据。康泰纳仕、家乐氏和新闻集团等众多客户正在将关键旧系统迁移至 AWS，有些甚至将整个数据中心迁移到 AWS。



我们的创新节奏也不断加快 —— 从 2012 年的近 160 个新功能和服务，增加到 2013 年的 280 个，2014 年达到 516 个。有很多值得一提的内容 —— 从 WorkDocs 和 WorkMail，到 AWS Lambda 和 EC2 容器服务，再到 AWS Marketplace。但为了简洁，我只讲一个：我们最近推出的 Amazon Aurora。我们希望 Aurora 能为客户提供一种应对非常重要（但也非常棘手）技术问题的新方式，那就是关系型数据库。Aurora 是一个兼容 MySQL 的数据库引擎，既具备高端商用数据库的速度和可用性，又拥有开源数据库的简单性和低成本。Aurora 的性能是传统 MySQL 数据库的五倍，而成本仅为十分之一。关系型数据库长期以来一直是组织和开发者的痛点，我们对 Aurora 感到非常兴奋。



我相信 AWS 是那种梦寐以求的商业服务之一，既能服务客户，也能在未来很多年带来可观的财务回报。为什么我如此乐观？原因之一是，机会的规模很大 —— 它涵盖服务器、网络、数据中心、基础设施软件、数据库、数据仓库等在内的整体 IT 支出。与我对亚马逊零售业务的看法类似，AWS 在市场规模上几乎没有限制。



第二，AWS 当前的领导地位（这一点非常重要）是一个持续的强大优势。我们非常努力地工作 —— 致力于让 AWS 尽可能易于使用。即便如此，它依然是一套功能丰富且学习曲线不低的复杂工具集。一旦你掌握了如何用 AWS 构建复杂系统，你就不会想再去学习一整套新工具和 API，尤其是当前的工具集已经对你非常有效。这绝不是我们可以满足现状的理由，但如果我们继续以真正卓越的方式服务客户，他们就会理性地选择继续与我们合作。



此外，也正因为我们处于领先地位，现在全球已有数千人实际上充当着 AWS 的“代言人”。软件开发者更换工作、从一家公司跳槽到另一家公司时，往往成了我们最好的销售人员：“我之前公司用的是 AWS，我们也该考虑一下。我觉得可以提升效率。”这是一个好现象 —— 熟练掌握 AWS 及其服务已经成为软件开发者简历中的加分项。



最后，我对 AWS 在资本回报方面保持强劲表现持乐观态度。这也是我们团队认真研究的一个主题 —— 因为 AWS 是资本密集型业务。好消息是，我们喜欢分析中得出的结果。从结构上来看，AWS 比它所替代的自建数据中心模式资本投入要少得多 —— 后者通常利用率很低，几乎总是低于 20%。将多个客户的工作负载集中处理能让 AWS 达到更高的资源利用率，从而带来更高的资本效率。此外，再次得益于我们的领先地位，规模经济为我们在资本效率上提供了相对优势。我们将持续关注并优化业务，以实现良好的资本回报。



AWS 仍然年轻，仍在不断成长与演进。我们认为，只要继续以客户需求为首要考虑来执行战略，就可以继续保持领先地位。



**职业选择（Career Choice）**



在结束前，我想花一点时间向股东们汇报一项我们感到兴奋和自豪的内容。三年前，我们推出了一项创新的员工福利计划 —— Career Choice 项目。在该项目中，我们为员工预付 95% 的学费，让他们就读航空机械、护理等热门专业，无论这些技能是否与在亚马逊的工作相关。这个想法很简单：赋予选择权。



我们知道，对于一些在我们履约中心和客户服务中心工作的员工来说，亚马逊可能就是他们的职业。而对于另一些人来说，亚马逊可能是通往其他工作的跳板 —— 一份可能需要新技能的新工作。如果合适的培训能带来改变，我们愿意帮助他们。到目前为止，我们已帮助八个国家中超过 2,000 名员工参与了该项目。由于项目反响热烈，我们现在开始在履约中心内建设专属教室，以便教授大学和技术课程，让员工更容易实现他们的目标。



目前，有八个履约中心提供 15 门课程，课程在这些专用教室中教授。教室配备高端技术设施，并采用玻璃墙设计，以激励其他人参与并相互鼓励。我们相信，Career Choice 是一种创新方式，可以吸引优秀人才加入我们的履约和客服团队。这些岗位可以成为通往亚马逊伟大职业生涯的入口，也可以让员工有机会在热门技术领域中追求热情。例如，我们的第一位 Career Choice 毕业生现在就在她的社区开启了作为护士的新职业。



我还想邀请你来亲自体验一下 —— 超过 24,000 人已在 Amazon.com 上点击报名参观我们的履约中心。除了美国，我们现在也在其他国家开放参观，例如英国的鲁格利和德国的格拉本，并会继续扩展。你可以通过 www.amazon.com/fctours 报名参观。



Marketplace、Prime 和 AWS 是三个伟大的创意。我们很幸运拥有它们，也下定决心要不断改进和培育它们 —— 让它们对客户变得更加优秀。你也可以指望我们继续努力，去创造第四个伟大的创意。我们已有不少候选项目在进行中，正如二十年前我们承诺的那样，我们会继续大胆下注。面对为客户服务而不断发明的新机遇，我们保证不会停止努力。



一如既往，我附上我们最初的 1997 年信件副本。我们的方法保持不变，因为这依然是 Day 1（第一天）。
