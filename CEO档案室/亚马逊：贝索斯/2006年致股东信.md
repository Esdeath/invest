# 2006年致股东信：



致我们的股东：



在 亚马逊当前的规模下，种下能够成长为有意义新业务的“种子”，需要一定的**纪律、耐心**，以及一种**培育文化**。



我们现有的业务就像是**扎根良好的年轻大树**。它们正在成长，拥有高资本回报率，并活跃于非常大的市场中。这些特性为我们启动任何新业务设定了极高门槛。**在我们动用股东资金启动新业务之前，必须确信该业务有能力实现投资人所期望的资本回报率**。此外，我们也必须说服自己：这个新业务能在规模上成长到足以在整个公司中具有重要地位的程度。



同时，我们还必须相信，这一机会当前仍未被充分开发，并且我们具备将客户体验创新引入市场的能力。否则，我们几乎不可能将其发展至规模化。



我常被问到：“你们什么时候会开线下实体店？”这是一个我们曾抵制的扩张机会。这个机会无法通过我们前面提到的测试。实体店网络的规模潜力无疑很大，也令人激动。但我们并不知道如何用低资本和高回报去实现它。传统实体零售是一个谨慎而又成熟的行业，早已有大量竞争者。我们也没有好的办法去构建一个能带来**显著客户差异化体验的实体门店模式**。



如果你看到我们进入某个新业务领域，那是因为我们相信它已经通过了上述测试。比如我们收购 Joyo.com，就是我们进军全球人口最多国家的第一步。中国的电商仍处于早期阶段，我们认为这是一项非常优秀的商业机会。鞋服、杂货、日用品：这些都是我们擅长的领域，能进行发明创新，并构建大规模、高回报的新业务，为客户带来真正的价值提升。



**亚马逊物流（FBA）就是一个例子，它是一组 API 服务，把我们1200万平方英尺的配送网络变成一个先进、智能的外部“计算机外围设备”**。你只需支付每立方英尺每月45美分的存储费，即可将产品存入我们的配送网络。你可以通过 API 请求我们查看库存、挑选和打包商品、或指定配送地址，**无需人工联系**。它具备差异化、有潜力，并且符合我们的回报标准。



**亚马逊云服务（AWS）**&#x662F;另一个例子。在这个全新领域，我们服务的是一个全新的客户群体——**软件开发者**。我们目前已提供10种不同的云服务，构建起了一个由24万注册开发者组成的社区。



我们正面向开发者普遍关注的领域，例如存储与计算容量——这是开发者多年一直在呼吁亚马逊提供帮助的方面。过去12年我们积累了大量经验，在这个领域我们准备充足，差异化明显，规模潜力巨大，并符合我们的投资回报标准。



在一些大公司中，由于耐心和培育文化的缺乏，从微小的“种子”中发展新业务是非常困难的。但在我看来，亚马逊的文化非常支持**具有巨大潜力的小型业务**，我认为这正是我们重要的竞争优势之一。



像所有公司一样，我们的企业文化不仅由我们的意图塑造，也深受我们发展历程的影响。对 亚马逊来说，这段历史还算年轻，幸运的是，其中包括了多个**从微小种子成长为参天大树的案例**。我们公司有许多员工，亲眼见证了多个千万美元级别的早期项目最终成长为**市值数十亿美元的业务**。这种一线经验和由此孕育出的文化，是我们能够从零启动新业务的重要原因。



这种文化要求新业务具备高潜力，要求它们具有创新性和差异化优势，但它**并不要求这些业务在“出生之日”就具有庞大规模**。



我还记得我们在1996年达到图书销售1000万美元时的兴奋——我们是从零做起的。如今，当 亚马逊内部某项新业务从1000万美元成长到1.001亿美元时，整个公司也从100亿增长到了101亿美元。对于那些负责管理成熟业务的高管来说，这种增幅可能微不足道，但他们不会轻视这些增长。他们会关注这些新业务的成长速度，并发来祝贺邮件。这种氛围很棒，我们也为这样的文化感到自豪。



根据我们的经验，即使一个新业务获得爆炸式成功，它也**至少需要3到7年**时间，才能对整个公司产生实质性影响。我们在国际业务、早期非媒体业务，以及第三方卖家业务中都见证了类似的发展周期。



如今，我们的销售结构如下：

* 国际业务占比：**45%**

* 非媒体业务占比：**34%**

* 第三方卖家业务占单位销量的：**28%**



如果我们现在播下的种子也能取得类似的成果，我们将感到非常欣慰。



自从我们首次庆祝“销售额破千万美元”以来，亚马逊已走过漫长旅程。未来，我们将继续**坚持支持新业务的文化**。我们将以纪律严谨的方式推进，关注**回报、潜力、差异化能力**等关键因素。我们未必总能做出正确选择，也不会事事成功。但我们会**审慎挑选、勤奋努力、耐心培育**。



一如既往，我附上了1997年的股东信。你会看到，我们的理念与方法至今未变。衷心感谢你们的支持与鼓励。
